A newspaper front page that sums up the world's news of Thursday 26 November 2026 in one image: a Houthi drone strike on a Saudi refinery (Brent crude tops $94), Trump's new tariffs on 14 partners, Russian jets near South Korea, Pakistan's first astronaut aboard China's space station, NATO's boosted air watch, plus a ticker with the Cairo tanker fire, the Colombia hostage rescue and US Thanksgiving travel chaos.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to `/output/entry.png`. The copy is byte-exact, so every run writes identical bytes. No network.
